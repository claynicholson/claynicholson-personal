## Your accounts
- **Kerberos identity** (username@mit.edu) — created before arrival; it's your login for everything. Choose the username carefully; it's ~permanent.
- **MIT email** — runs on Microsoft 365/Outlook (with forwarding options). Email-for-life alumni forwarding exists.
- **Touchstone** — MIT's single sign-on; **Duo** two-factor is mandatory.
- **MIT ID card** — building access, TechCASH, library borrowing.

## Athena
MIT's campus computing environment (Linux workstations in clusters across campus + `athena.dialup.mit.edu` for SSH). Clusters have free black-and-white printing. Your **Athena locker** gives you AFS storage and simple web hosting at web.mit.edu/username. Course 6 classes lean on Athena less than they used to, but dialup + lockers remain handy.

## Free and discounted software
IS&T's software grid (ist.mit.edu) provides free-to-students licenses: **MATLAB, Mathematica, Microsoft Office, Solidworks (via some departments), VPN (GlobalProtect), antivirus**, and cloud credits/education tiers via GitHub Student Pack etc. Never pay for software before checking the grid.

## Networks
- **MIT SECURE** wifi everywhere on campus; **eduroam** works at other universities; wired ports in dorms.
- Every device gets a public-facing setup historically famous for MIT's /8 — today expect standard NAT/registration via IS&T.
- **MIT VPN** for off-campus access to licensed resources.

## Printing
- Free B&W printing in Athena clusters (quota-based) via Pharos — release jobs at any cluster printer.
- Color/poster printing: CopyTech (11-004) at reasonable prices — the standard spot for UROP poster sessions.

## Help
- **IS&T Service Desk** (helpdesk, walk-in in W20/E17 area — check current location) and the **Knowledge Base (kb.mit.edu)**.
- Student-run help: dorm computing chairs, SIPB (Student Information Processing Board, W20-557) — the student computing group that runs services like scripts.mit.edu, XVM, and Mattermost-era chat tools; visit them for hosting/nerd help.
